## Features
| Section | What it does |
|---|---|
| **Impact readout** | Animated scan panel that plays key metrics from my work, like raising SLA compliance from 78% to 92% |
| **Experience timeline** | Tabbed view of each part of my role, with a progress line that fills as you scroll |
| **Projects** | Expandable cards for GRC, cloud security, DFIR, penetration testing and cryptography projects |
| **Security Lab: Terminal** | A working command line. Try `help`, `whoami`, `skills`, `nmap cybersus` or `hire siddhi` |
| **Security Lab: Triage Challenge** | Prioritise 5 realistic vulnerabilities (P1 to P4) using CVSS, exposure and exploit status, with an explanation after each answer |
| **Security Lab: Password Lab** | Live entropy, estimated offline crack time and strength checks. Runs entirely in the browser, and nothing is stored or sent |
| **Skills wall** | Tool and framework tags you can filter by area |
| **Credentials** | Certifications (earned and in progress) and competition rankings |

## Tech stack
- **HTML5, CSS3 and vanilla JavaScript.** No frameworks, no build step and no dependencies.
- **Canvas API** for the animated brick wall and scan beam in the hero.
- **CSS Grid and Flexbox** for a responsive layout that works from phone to desktop.
- **Google Fonts:** Bricolage Grotesque, IBM Plex Sans and JetBrains Mono.
- **Netlify** for hosting, deployed automatically from this private repository.
  
## Security and privacy
- The site is fully static, with no backend, database, cookies or tracking.
- The password lab runs locally in the visitor's browser, and input is never stored or transmitted.
- No client or employer data is included. All lab scenarios are fictional examples.
- The source repository is private. Access is granted on request
